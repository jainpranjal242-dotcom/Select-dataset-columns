# Select Dataset Columns Project

**Student:** Pranjal Jain

This project demonstrates Pandas `loc` and `iloc` using an Iris dataset practice sample.

### Included
- Jupyter Notebook with `loc` examples
- Jupyter Notebook with `iloc` examples
- Row + column selection
- Boolean filtering
- Selected-record outputs
- Project report
- Dataset CSV
- Requirements file

### Run
`pip install -r requirements.txt`

Open `Select_Dataset_Columns_Practice.ipynb` in Jupyter Notebook or VS Code and run all cells.
